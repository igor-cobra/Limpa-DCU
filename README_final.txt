SOBRE OS TEMAS E ARQUIVOS .VSF

O projeto foi pensado para priorizar o mecanismo visual do próprio Delphi, mas também aceita arquivos .vsf externos como medida adicional de segurança e controle.

Na prática, isso ajuda bastante quando se deseja:

- padronizar o visual entre diferentes máquinas;
- evitar dependência exclusiva da configuração local do ambiente;
- distribuir o aplicativo com os estilos já esperados;
- testar ou homologar comportamentos visuais específicos;
- utilizar temas customizados compatíveis com a aplicação.

Se desejar usar os estilos externos, coloque os arquivos na pasta:

styles\
  Aqua Light Slate.vsf
  Glow.vsf

Essa pasta deve ficar ao lado do executável do sistema.

Se os arquivos não estiverem presentes, o aplicativo continuará funcionando com o tema de fallback definido internamente. Ou seja, a ausência dos .vsf não impede o uso do sistema, apenas altera a forma como o tema visual será resolvido.
